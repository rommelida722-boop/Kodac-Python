# 第一期：长上下文完整性

## 问题与修改

参考本地 `docs1/phase-12-long-context.md` 中关于保留近期完整工具轮次的要求，改进 Python 上下文压缩模块。

1. 原实现优先寻找用户消息作为保留边界；在没有用户消息的历史片段里，可能从 tool 结果中间开始保留。现在会向前回退到连续工具结果之前的 assistant 调用，避免拆开调用组。
2. 原实现仅复制外层字典，嵌套工具参数和图片结构仍可能被共享。现在对消息内容与工具调用使用深拷贝，使原历史和压缩结果相互独立。

## 验证

新增两项回归测试：无用户消息时连续工具结果仍与调用一起保留；修改副本中的嵌套参数不影响原消息。上下文测试共 7 项通过。
